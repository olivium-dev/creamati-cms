# Container layout config

**Navbar and footer are configurable** via `layoutConfig.json`.

- **`navbar.title`** — Text shown in the top app bar (e.g. "Creamat CMS").
- **`footer.text`** — Full footer text (e.g. "© 2025 Creamat CMS. Built with React + MUI.").

Edit `layoutConfig.json` and rebuild/refresh. If the file is missing or invalid, defaults (Creamat CMS) are used.
